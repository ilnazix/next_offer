# Агент-«Проактивный консьерж»

## 1. Общее описание

**Название проекта:** Агент-«Проактивный консьерж» для жизненных сценариев Клиента

**Продукт:** ИИ-агент, интегрированный в мобильное приложение «АК БАРС Онлайн»

**Концепция:** В методологии розницы важно не только отвечать на вопросы, но и формировать потребность. Агент анализирует транзакции и историю клиента, чтобы предложить продукт в нужный момент, превращая банк из «расчётного центра» в советника.

**Каналы коммуникации:**
- Раздел «Чат» в мобильном приложении
- Пуш-уведомления (автоотправка по шаблонам, без создания заявки на маркетинговые коммуникации в Jira)

## 3. Триггеры для предложений

### 3.1. Транзакционные триггеры (движение денег)

Основаны на реальном поведении клиента.

| № | Триггер | Условие срабатывания | Оффер |
|---|---|---|---|
| 1 | Поступление крупной суммы (зарплата, премия, бонусы) | На счёт поступило на 30–50% больше обычного или разово крупная сумма, и клиент не тратит её в течение 3–5 дней | «Сохраните премию под высокий процент» — вклад/НС |
| 2 | Остаток на конец месяца (End of Month Balance) | Клиент стабильно держит на текущем счете сумму, превышающую среднемесячные траты в 2–3 раза | Накопительный счёт с возможностью снятия |
| 3 | Снятие крупной суммы наличных или перевод в другой банк | Клиент выводит деньги / переводит себе на карту другого банка | «Оставьте средства в банке, получите +X%» / «Нужны наличные? Оформите кредит наличными» |
| 4 | Оплата крупных покупок (Down Payment) | Транзакции в мебельных, строительных магазинах, автосалонах | Накопительный счёт на первоначальный взнос или ремонт / «КЗА/КЗН» |
| 5 | Кассовый разрыв (до зарплаты) | Баланс падает ниже 5% перед привычной датой поступления зарплаты (по данным за 3 месяца) | «До зарплаты ещё далеко? Предодобренный кредит наличными» |
| 6 | Погашение кредита | Клиент закрыл кредит, высвободились средства | «Перенаправьте платёж на накопление» |
| 7 | Регулярные денежные поступления от физических/юридических лиц | Повторяющиеся входящие переводы | Вклад/НС |

**Фильтры для группы:** у клиента нет действующего НС, количество действующих вкладов — не более 1 шт.  
Дополнительно для №3 — отсутствие подписки.

---

### 3.2. Триггеры жизненных событий (демография и статус)

Банк видит изменения в профиле клиента или паттернах трат.

| № | Триггер | Условие срабатывания | Оффер |
|---|---|---|---|
| 1 | Смена работы / выход на пенсию | Поступление первой зарплаты от нового работодателя или пенсии | Вклад для пенсионеров или НС |
| 2 | Свадьба / рождение ребёнка | Всплеск трат в категориях «Рестораны», «Цветы», «Детские товары» | Накопительный счёт |
| 3 | Сезонность (отпускной период) | Май–август, траты на путешествия | Накопительный счёт для отпуска |
| 4 | Налоговый период | Апрель–июль (уплата налогов или получение вычетов) | «Разместите налоговый вычет на вклад/накоп.счёт» |
| 5 | Дни рождения | За 3 дня до ДР, в сам день и 3 дня после | Накопительный счёт/вклад для приумножения полученной суммы |
| 6 | Переезд / ремонт | Покупки в строительных магазинах («Леруа»), оплата ЖКХ по новому адресу, у клиента есть недвижимость в собственности | «Делаете ремонт? Оформите кредит под залог недвижимости (КПЗН), деньги на любые цели» |

**Фильтры для группы:** у клиента нет действующего НС, количество действующих вкладов — не более 1 шт.

### 3.3. Цифровые триггеры (поведение в приложении и на сайте)

Действия клиента в мобильном банке или на сайте банка.

| № | Триггер | Условие срабатывания | Оффер |
|---|---|---|---|
| 1 | Поиск вкладов | Клиент заходил в раздел «Вклады/Счета» или использовал калькулятор на сайте, но не открыл продукт | Догоняющий push |
| 2 | Изучение аналитики расходов | Клиент часто смотрит графики расходов/доходов | «Вы тратите меньше, чем зарабатываете — отложите разницу» |
| 3 | Брошенная заявка | Начал оформлять вклад, но ушёл на этапе подтверждения | Догоняющий оффер |
| 4 | Просмотр новостей об инфляции / ключевой ставке | Читает блог банка на финансовые темы (Ак Барс Life) | Релевантный вклад/НС |
| 5 | Использование кредитного калькулятора | Рассчитывал платёж по ипотеке или автокредиту, но не оставил заявку | «Ваш расчёт сохранён. Получите предварительное решение онлайн» |
| 6 | Изучение раздела «Кредиты» | Часто заходит в раздел с кредитными продуктами, читает условия, но не нажимает «Оформить» | «Подобрали для вас персональное предложение» |

**Фильтры для группы:** у клиента нет действующего НС, количество действующих вкладов — не более 1 шт.

### 3.4. Продуктовые триггеры (изменения в портфеле)

| № | Триггер | Условие срабатывания | Оффер |
|---|---|---|---|
| 1 | Окончание срока предыдущего вклада | За 3–5 дней до окончания депозита | Пролонгация на новых условиях или перекладывание в НС |
| 2 | Окончание промо-периода | Заканчивается повышенная ставка на НС (например, первые 3 месяца) | Переход на новый вклад |
| 3 | Истечение срока действия карты | При перевыпуске карты | Предложить сопутствующий НС |
| 4 | Снижение трат | Клиент резко сократил расходы по карте по сравнению с прошлым месяцем | «Свободные средства — на вклад» |
| 5 | Получение кешбэка | Клиент получил крупный кешбэк на карту | «Капитализируйте кешбэк» |
| 6 | Исчерпание лимита кредитной карты | Потратил > 80–90% лимита по кредитке | «Лимит почти исчерпан? Оформите кредит наличными, чтобы рефинансировать долг» |
| 7 | Погашение кредита | Клиент досрочно закрыл кредит наличными | «Вы закрыли кредит! Предодобренный лимит сохранён» |

**Фильтры:**
- №1–2: у клиента есть действующий вклад/НС
- №3: у клиента нет НС
- №4–5: у клиента нет действующего НС, количество действующих вкладов — не более 1 шт.

## 4. Глобальные фильтры (актуальны для большинства триггеров)

- У клиента **нет действующего накопительного счёта (НС)**
- Количество **действующих вкладов ≤ 1**

Фильтры могут варьироваться в зависимости от конкретного триггера (см. примечания к группам).

## 5. MVP: scope и ограничения

**Горизонт:** один вечер / ASAP

**Принцип:** взять узкий end-to-end slice, который доказывает концепцию, — не пытаться реализовать все 26 триггеров.

### 5.1. Триггеры в MVP

| № | Триггер | Почему взяли |
|---|---|---|
| 1 | Поступление крупной суммы | Понятная транзакционная логика, легко смоделировать на тестовых данных |
| 2 | Остаток на конец месяца | Демонстрирует аналитику по истории, не только последнему событию |
| 3 | Просмотр раздела «Вклады» без открытия | Покрывает цифровой триггер и канал догоняющего push |

### 5.2. Архитектура MVP

```
[Тестовые данные: клиенты + транзакции + события в приложении]
                    ↓
        [FastAPI: Agent Core]
        ├─ Rule Engine (3 триггера)
        ├─ Product Eligibility Filter (НС/вклады)
        ├─ LLM Prompt для генерации текста оффера
        └─ Хранение: SQLite
                    ↓
        [API для мобильного приложения]
        ├─ POST /events        → приём события
        ├─ GET  /clients/{id}/offers → список офферов клиента
        └─ POST /offers/{id}/feedback → реакция (принял/отказал)
                    ↓
        [Mock UI: чат + карточка оффера]
```

### 5.3. Стек

| Слой | Технология |
|---|---|
| Backend | Python + FastAPI |
| Хранение | SQLite (или in-memory) |
| LLM | Yandex GPT / GigaChat API / Ollama (локально) |
| Mock mobile UI | HTML + JS |
| Тестовые данные | CSV / JSON |

### 5.4. План работы на вечер

| Этап | Время | Результат |
|---|---|---|
| 1. Подготовка данных | 30 мин | 10–20 тестовых клиентов с историей транзакций |
| 2. Скелет API | 30 мин | FastAPI с endpoints `/events`, `/offers` |
| 3. Rule Engine | 1 час | 3 триггера + фильтры по НС/вкладам |
| 4. LLM-генерация текста | 30 мин | Промпт и интеграция с выбранным провайдером |
| 5. Mock UI | 30 мин | Экран чата + карточка предложения |
| 6. End-to-end тест | 30 мин | Проверка: событие → оффер → отображение |

## 6. Открытые вопросы (блокеры перед стартом разработки)

1. **LLM-провайдер:** какой API доступен? (Yandex GPT / GigaChat / OpenAI / локальная модель через Ollama?)
2. **Тестовые данные:** генерировать синтетику самостоятельно или есть готовый тестовый датасет?
3. **Формат демо:** достаточно Postman/CLI или нужен визуальный мок экрана мобильного приложения?
4. **Продуктовые условия:** какие реальные ставки и названия продуктов использовать в офферах, или можно фейковые («Вклад под 8%»)?
5. **Канал:** в MVP имитировать и пуш, и чат, или сфокусироваться только на чате?
