# 006: Rule engine и генерация офферов

**Label:** `wayfinder:prototype`

## Question

Как rule engine будет принимать решения, и как LLM будет генерировать тексты офферов?

Конкретно нужно решить:
1. Архитектура rule engine (pure Python функции, decision table, или что-то более сложное)?
2. Как rule engine получает контекст (текущая транзакция + история клиента)?
3. Как происходит matching триггеров с продуктами?
4. Как интегрируется LLM: только для текста или также для ранжирования?
5. Как выглядит промпт для LLM?
6. Нужно ли кеширование/идемпотентность офферов?
