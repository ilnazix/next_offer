# 001: Выбор LLM-провайдера и способа интеграции

**Label:** `wayfinder:research`

## Question

Какой LLM-провайдер и способ интеграции использовать в MVP агента «Проактивный консьерж»?

Конкретно нужно решить:
1. Какой провайдер выбрать: Yandex GPT, GigaChat, OpenAI, локальная модель (Ollama, vLLM) или другой?
2. Где будет происходить инференс: локально в docker-compose, в корпоративном API банка, или через внешний SaaS?
3. Какие данные отправляются в LLM (полные транзакции, анонимизированный контекст, только готовый промпт)?
4. Какой бюджет/лимиты приемлемы для MVP?
5. Нужна ли возможность быстро переключаться между провайдерами (абстракция)?

## Context

- Проект разворачивается локально в docker-compose.
- Данные тестовые/синтетические, но архитектурно нужно закладывать безопасность.
- MVP за вечер: решение должно быть быстрым в интеграции.
- LLM используется для генерации текста оффера на основе контекста клиента и выбранного продукта.
