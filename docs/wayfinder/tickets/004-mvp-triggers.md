# 004: Финализация триггеров MVP

**Label:** `wayfinder:grilling`

## Question

Какие именно триггеры и правила срабатывания войдут в MVP?

Из `docs/requirements.md` есть 26 триггеров. Нужно выбрать 3 и чётко описать условия:
1. Какой транзакционный триггер берём (поступление крупной суммы / остаток / что-то ещё)?
2. Какой цифровой триггер берём (просмотр вкладов / брошенная заявка / аналитика)?
3. Берём ли триггер жизненного события или продуктовый?
4. Какие точные пороги и условия (сумма, период, проценты)?
5. Какие продукты предлагаем при каждом триггере?
6. Как учитываем фильтры (наличие НС, количество вкладов)?

## Context

- Фильтры: нет действующего НС, действующих вкладов ≤ 1.
- Цель MVP — показать проактивное предложение в нужный момент.
