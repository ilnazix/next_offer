# 003: Генератор тестовых данных

**Label:** `wayfinder:task`

## Question

Как организовать генерацию синтетических тестовых данных для MVP?

Конкретно нужно решить:
1. Какие сущности генерируем (клиенты, счета, карты, транзакции, события в приложении, продукты)?
2. Какой объём данных достаточен для демо (10, 100, 1000 клиентов)?
3. Генератор — отдельный скрипт, отдельный контейнер или часть FastAPI-приложения?
4. Как обеспечить воспроизводимость (seed)?
5. Какие сценарии должны быть в данных, чтобы сработали 3 триггера MVP?

## Context

- Данные тестовые/синтетические.
- 3 триггера MVP требуют специфических паттернов: крупное поступление, высокий остаток, просмотр вкладов.
