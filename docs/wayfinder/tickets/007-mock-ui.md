# 007: Mock UI чата

**Label:** `wayfinder:prototype`

## Question

Как должен выглядеть и вести себя mock UI чата для демо MVP?

Конкретно нужно решить:
1. Технология: простой HTML+JS, React-заглушка, или CLI?
2. Как выглядит карточка оффера (текст, кнопки действий, иконка продукта)?
3. Какие действия доступны пользователю (принять, отказаться, подробнее)?
4. Как mock UI получает офферы (polling, WebSocket, или однократный запрос)?
5. Нужна ли симуляция входящего события (кнопка «совершить транзакцию»)?

## Context

- MVP канал = чат.
- Демо должно наглядно показывать, как агент проактивно предлагает продукт.
